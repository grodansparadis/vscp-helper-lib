# Error Handling


* A successful function response is either an object or the integer `VSCP_ERROR_SUCCESS`.
* A failed function response is either `NULL` or the integer `VSCP_ERROR_ERROR`.
* Other return codes are listed in [vscp.h](https://github.com/grodansparadis/vscp_software/blob/master/src/vscp/common/vscp.h).
