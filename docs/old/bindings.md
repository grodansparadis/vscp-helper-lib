# VSCP Helper Library bindings

## C/C++

Available on Windows and Linux.

The libvscphelper library is available in deb package format for 64-bit Linux and Windows.

If you are using an i386-based machine, you need to [install this](https///debian.pkgs.org/9/debian-main-i386/libwxbase3.0-0v5_3.0.2+dfsg-4_i386.deb.html) before installing the package.

Files are available [here](https://www.vscp.org/downloads/vscphelper).
## Python

**pyvscp** is the official Python support for VSCP & friends. Install it with:

    pip install pyvscp

On Windows, run **cmd** as an administrator and use:

    python -m pip install pyvscp

The source code is available [here](https///github.com/grodansparadis/pyvscp).

To import the library:

    from vscp import vscp, vscp_class, vscp_type, vscpudp, vscptcp, vscphelper

or

    from vscp import *
    
----

Code written by **Salvo Musumeci** is also available [here](https///github.com/nos86/VSCP-Helper-for-Python).
