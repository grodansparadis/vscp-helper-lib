# Abstract

The VSCP helper library provides tools for developing VSCP applications. It includes functions for working with Level I drivers (formerly called CANAL drivers), communicating with a remote VSCP daemon (Level II) over TCP/IP, and performing other common tasks. It includes helper and communication functions and supports threads for receiving and transmitting events.

The library is currently available for Unix/Linux and for Windows.
